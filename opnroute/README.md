# OPNSENSE router (OpnRoute)
-Opnsense 26.1.6
-6gb RAM
-2 CPU cores
-WAN: vmbr0(ISP/family network) 192.168.x.x
-LAN: vmbr1(internal lab net) 10.10.x.x
-segmented VLANs
-Wireguard vpn
-Firewall rules

## Purpose
This Opnsense vm was created to help me practice networking in my homelab. It's used to isolate the lab environment from my normal family network.
